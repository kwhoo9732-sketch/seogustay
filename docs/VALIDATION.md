- `public/`에서 HTML을 제외한 21개 파일은 원본과 바이트 단위로 동일함을 확인했다.
- HTML에서는 기존 배포 도메인으로 고정된 `og:url` 메타태그만 제거했다. 화면 구성·문구·로컬 자료 경로는 보존했다.

## 실행·서버

- `npm run build` 통과: 정적 참조 파일·JSON·GeoJSON·JavaScript 구문·API 진입점 확인.
- `npm test` 통과: **11개 성공, 0개 실패**.
- 출처·입력 크기 제한, 비밀값 비노출, Redis 설정·오류 차단, 한도 초과 시 Solar 미호출을 확인했다.
- 최대 3개까지 고르는 모든 지원 생활조건 조합에서 서버 결과와 기존 브라우저 비교 모듈이 일치한다.
- 배포 Lua 문자열을 로컬 Lua 5.4에서 실행해 세 버킷 일괄 검사·차감, 거절 시 무차감, TTL 48시간을 확인했다. 이 검사에서 Redis 명령은 모의 저장소를 사용했으며 실제 Redis 동시성·네트워크 검증은 아니다.
- 실제 API 키·Redis 연결을 사용한 제공자 호출은 실행하지 않았다. 운영자가 연결 정보를 등록한 뒤 실제 응답을 확인해야 한다.

## 실제 브라우저 확인

- 첫 화면 호수 사진·제목·탐색 메뉴와 공동주택 239개 범위 표시를 확인했다.
- `공원과 초등학교가 가까운 집을 찾고 싶어요`를 입력했을 때 기본검색으로 조건 2개를 해석하고 결과를 표시했다.
- 기본 결과 231개, 모든 조건 확인·충족 26개를 표시하고 전체 결과에 조건을 적용했다.
- 전체 충족 필터를 선택하면 26개 단지로 좁혀졌고, 현재 페이지의 위치 확인 단지 24개가 지도와 연결됐다.
- 가격자료가 없는 광천모아엘가 상세에서도 위치·주변 학교·명소와 거래자료 미수록 안내를 확인했다.
- 관심 단지 1개를 저장하고 새로고침 후에도 1개가 유지됨을 확인했다.
