# 서구STAY 자료·검색 기준

전남광주통합특별시 서구에서 원하는 생활 조건으로 집을 찾고, 조건에 맞는 이유와 주변 환경을 살핀 뒤 확인된 거래가격을 이해하는 주거·생활정보 시범 사이트다. 현재 입주 가능한 매물을 중개하는 서비스는 아니다.

이 문서는 GitHub·Vercel 이전본에 포함한 자료의 출처, 수록 범위와 검색 기준을 설명한다. 실행·배포·선택적 AI 연결 설정은 저장소의 [README](../README.md)를 따른다. 자료 파일을 옮긴 날짜와 원자료의 기준일을 구분한다.

## 생활 가이드의 역할

2026-10-29 기존 버전에 호수 사진 중심의 첫 화면과 문장으로 생활 조건을 입력하는 가이드를 추가했다. 이전본에서도 [첫 화면](../public/index.html), [화면 스타일](../public/stay.css), [생활 가이드](../public/guide.js), [조건 비교 모듈](../public/matching.js)을 유지한다.

- Solar를 연결하면 문장을 최대 3개의 생활 조건, 동네, 명시적 매매 예산 상한, 단지명으로 정리한다. 실제 단지와 거리·면적·준공연도 비교는 수록 자료에 근거해 계산하며, AI 답변과 자료 미확인 상태를 구분한다.
- 가이드 결과에서 단지 상세와 전체 검색 결과로 이동할 수 있다. 후속 질문에는 최근 2회의 문맥을 전달하며 브라우저의 대화 내역은 메모리에만 둔다. AI 모드의 입력 문장은 답변을 위해 Upstage로 전송된다.
- AI가 준비되지 않은 경우 브라우저의 기본 문장 조건검색을 제공하고, AI 생성 답변이 아님을 표시한다. AI 오류·사용량 제한 시에도 생활 조건 선택과 기존 단지 탐색은 이용할 수 있다.
- AI 연결 상태와 별개로 아래에 명시한 정적 자료의 수록 범위가 적용된다. AI를 연결해도 누락된 실거래·좌표·학군 정보가 자동 수집되는 것은 아니다.

K-apt에서 추가한 단지는 해피투모루, 상무리채2차, 위파크더센트럴, 위파크마륵공원아파트, 상무양우내안애퍼스트힐이다. 서구청 원본에는 주택 유형 열이 없으므로, 유형을 별도로 확인하지 못한 항목은 **공동주택**으로 표시한다. 모든 항목을 아파트라고 단정하지 않는다. 원자료 주소와 현재 화면의 지역 표시명은 데이터에서 구분하며 행정코드를 추정해 바꾸지 않는다.

모든 자료는 정적 스냅샷이다. 목록 기준일 이후 신규·변경 단지, 모든 거래·생활시설, 현재 현장 상태를 실시간으로 반영하지 않는다.

## 사용자 흐름과 검색

1. **7개 생활 조건에서 최대 3개**를 고른다. 선택 없이 전체 목록을 둘러볼 수도 있다.
2. 결과에서 시설·학교 이름과 직선거리, 대표 거래의 전용면적, 준공연도 등 **조건을 비교한 실제 값**을 확인한다.
3. 단지 상세에서 기본정보·학교·명소를 살피고, 거래자료가 있으면 **금액·전용면적·층·계약일을 함께** 읽는다. 관심 저장과 최대 3개 단지 비교를 지원한다.

기본 정렬은 선택 조건의 **충족 개수 내림차순**, 동률은 **단지 이름 가나다순**이다. 가격은 기본 정렬에 사용하지 않는다. 조건이 없으면 전체 단지를 이름순으로 보여준다.

조건을 선택한 기본 결과에는 하나 이상 충족한 단지와 **미확인 조건이 하나 이상 있는 단지**를 남긴다. 충족이 0개이고 미확인도 없는 단지만 제외한다. 미확인은 충족 개수에 더하지 않으며, **‘선택 조건 모두 맞는 집만’**을 켜면 모든 선택 조건을 확인해 충족한 단지만 남는다. 기준을 자동으로 완화하지 않는다.

- 가격자료가 없는 단지도 이름·별칭·주소·동네로 검색하고 상세·비교·관심 저장을 이용할 수 있다.
- 접힌 보조 검색에서 동네·대표 거래 전용면적·거래금액을 좁힌다. **면적·금액 필터는 해당 거래값이 확인된 단지만** 남긴다.
- 가격·계약일 정렬에서는 해당 거래자료가 없는 단지를 뒤에 둔다.
- 추가 검색 초기화는 생활 조건·전체 충족·관심 단지 설정을 유지한다. **전체 단지 보기**는 이 설정도 함께 해제한다.
- 목록은 **24개씩** 표시한다. 지도는 **현재 페이지에서 위치가 확인된 단지만** 표시하고 목록 번호를 공유한다. 위치 미확인 단지는 목록에 남기며 주소로 외부 지도를 검색할 수 있다.

## 생활 조건의 비교 기준

서비스에서 확인 가능한 자료를 비교하기 위해 정한 기준이다. 거주 만족도나 집의 품질을 평가하는 점수, 학교의 교육 수준 또는 배정 가능성을 뜻하지 않는다.

| 조건 | 충족 기준 |
| --- | --- |
| 공원·호수 가까이 | 운천저수지·풍암호수·상무시민공원·5·18기념공원 중 직선 1.5km 이내 |
| 문화공간 가까이 | 김대중컨벤션센터·빛고을국악전수관·서창한옥문화관 중 직선 1.5km 이내 |
| 양동시장 가까이 | 양동시장까지 직선 1.5km 이내 |
| 초등학교 가까이 | 서구 내 수록 초등학교 중 가장 가까운 학교까지 직선 500m 이내 |
| 중학교 가까이 | 서구 내 수록 중학교 중 가장 가까운 학교까지 직선 500m 이내 |
| 전용 84㎡ 이상 | 대표 표시 거래 사례의 전용면적 84㎡ 이상 |
| 2020년 이후 준공 | 자료에 기재된 준공연도 2020년 이상 |

명소 조건은 표에 적은 장소만 계산한다. 학교도 서구 내 수록 학교만 사용하므로 인접 구의 더 가까운 학교는 포함되지 않을 수 있다. 기준 밖이라는 결과는 주변에 해당 시설이 없다는 뜻이 아니다.

면적 조건은 표시 가격과 같은 `transactions[0]` 사례에 연결한다. 단지의 모든 평형·방 개수·평면을 나타내지 않는다. K-apt 사용승인일에서 추출한 연도와 기존 확인 자료의 준공연도는 출처와 함께 보존하며, 연도로 내부 상태나 관리 수준을 추론하지 않는다.

누락 자료는 미확인으로 유지한다. 비교 모듈은 거리 미터·면적 ㎡·연도 정수를 사용하고, 표시용 반올림 전 값으로 충족 여부를 판단한다. 특정 조건을 평가할 자료가 전혀 없으면 해당 선택지를 비활성화하고 이유를 안내한다.

## 가격·위치 정보의 한계

### 거래가격

가격은 쏙집·DHOME에 공개된 국토교통부 자료 재가공 정보에서 확인한 **8개 단지의 28건**이다. 단지별 대표 사례는 두 공개 페이지에서 교차 확인했다. 국토교통부 API 직접 연동이나 전체 거래 수집은 아니다.

금액은 특정 전용면적·층·계약일의 매매 사례이며 현재 호가·단지 평균·전체 시세가 아니다. 같은 전용면적의 일부 과거 사례만 수록하므로 시계열 전체·월평균·상승률로 표현하지 않는다. 확인 당시 해제 또는 출처 불일치로 확인된 거래는 제외했지만 이후 신고·정정·해제는 자동 반영되지 않는다.

**거래자료 미수록은 실제 거래가 없거나 가격이 0원이라는 뜻이 아니다.** 임의의 가격·면적을 채우지 않고 단지명·주소와 공식 원자료 확인 경로를 제공한다.

### 위치와 거리

좌표는 기존 공개 지도 링크와 공식 명칭·주소를 대조한 OpenStreetMap 건물·주거단지의 대표 위치를 사용한다. 단지별 위치 출처와 대조 근거를 보존한다. 동네 중심점이나 임의 좌표로 빈값을 채우지 않는다.

위치가 확인되지 않은 단지는 마커·주변 거리 계산에서 제외한다. 확인된 단지도 대표점과 실제 동·출입구가 다를 수 있다. 모든 거리는 직선거리이며 도보·차량 이동거리, 이동시간, 통학로를 뜻하지 않는다.

OpenStreetMap에서 추가한 좌표와 근거는 [data-coordinate-evidence.json](../public/data-coordinate-evidence.json)에 **ODbL-1.0**으로 제공한다. 넓은 지역의 평균좌표 또는 이름이 비슷하다는 이유만으로 연결한 좌표는 사용하지 않는다.

## 학군·학교

[data-schools.json](../public/data-schools.json)은 한국교육시설안전원 공식 학교 위치 CSV에서 서구에 있고 운영 중인 52교를 추출했다. 실제 첨부 데이터기준일은 **2026-10-01**로, 게시글 제목의 2026-09-20과 구분한다. 학교 누리집은 교육청 공개 CSV의 **2025-11-09** 자료를 연결한 것으로, 개별 사이트의 현재 운영 여부를 전수 확인한 정보는 아니다.

[data-education.json](../public/data-education.json)의 학구도 대조 결과는 **기존 8개 단지만** 수록한다. 2026-09-20 기준 초등 통학구역·중학교 학교군 도형에 대표 좌표를 대조했으며, 원본 출처·해시·도형 및 학교 연계 근거를 보존한다. 모든 결과는 `assignmentConfirmed: false`인 **지도 기준 참고 정보**다.

추가 단지는 좌표가 있으면 가까운 학교와 직선거리를 계산할 수 있다. 이는 통학구역 대조 결과나 배정 학교를 추가했다는 뜻이 아니다. 실제 입학·전입 대상은 상세 주소·아파트 동·해당 학년도 고시와 교육지원청 안내로 확인해야 한다.

중학교 학교군 전체 명단을 개별 단지의 지원 가능 목록으로 사용하지 않는다. 2027학년도 계획의 게시 사실은 확인했지만 초등학교별 개별 배정표를 검증·수록한 것은 아니다. 고교는 공고 제2026-10007호(2026-07-10) 첨부 요강의 **2027학년도 종전 광주 지역 평준화 후기 일반고** 배정 원칙을 안내한다. 속표지에 ‘안’ 표기가 남아 있어 별도 최종 확정본으로 표현하지 않으며, 재학생 전입학·학교 유형별 전형은 별도 확인 대상이다.

원본·추출본·대조 기록과 다운로드 근거는 [data-sources](../data-sources/), 준비·대조·병합 절차는 [scripts](../scripts/)를 참조한다. K-apt 전국 XLSX 원본 전체는 배포 데이터에 포함하지 않으며, 서구 추출본에 원본명·추출일·출처·SHA-256을 보존한다. 파일 제목의 날짜, 실제 데이터 추출일, 서비스 확인일을 서로 대체하지 않는다.

**원자료 전체의 자동 수집·실시간 갱신은 지원하지 않는다.** 동봉한 준비·대조·병합 스크립트는 확보한 스냅샷을 가공하는 절차다. 실행만으로 최신 단지·실거래·학교 자료를 외부에서 새로 수집하지 않는다. 원자료를 바꾸는 경우 출처·기준일·ID 대응·결측 상태를 함께 검토해야 한다. [기존 데이터 정합 보고](../data-sources/MATCHING-REPORT.md)에 남아 있는 과거 작업 경로와 조사 단계의 수치는 당시 이력이며, 현재 저장소에서 그대로 실행할 명령이나 최종 배포 데이터의 집계값으로 사용하지 않는다.

관심 단지는 브라우저 저장공간에 식별자만 저장하고, 비교 목록은 메모리에 최대 3개 유지한다. 도메인을 바꾸면 기존 관심 단지가 자동으로 옮겨지지 않으므로 [이전 시 참고사항](MIGRATION_NOTES.md)을 확인한다. 회원가입·분석 추적·문의 접수·중개 기능은 없다. Leaflet과 정적으로 포함한 GeoJSON을 사용하며 방문 시 외부 타일 서버나 Overpass로 지리자료 요청을 보내지 않는다.
