# 도메인 이전 시 참고사항

- 관심 단지는 브라우저의 `localStorage`에 `seogustay:saved:v1` 키로 저장된다. 저장값은 단지 ID 문자열의 배열이다.
- 기존 사이트와 Vercel 사이트는 도메인이 다르므로 같은 브라우저에서도 저장공간이 분리된다. 기존 관심 단지가 새 주소로 자동 이동하지 않는다.
- 같은 키를 유지해도 다른 도메인의 저장공간을 직접 읽을 수 없다. 현재 앱에는 관심 단지 내보내기·가져오기 기능이 없다.
- 기존 관심 단지를 계속 참고하려면 이전 사이트의 관심 목록을 확인해 새 사이트에서 다시 저장한다. 새 사이트를 처음 열었을 때 관심 단지 수가 0개인 것은 목록 데이터가 사라진 것이 아니다.
- 단지 ID는 학교·위치 근거 연결에도 사용되므로, 데이터를 보강할 때 기존 ID를 유지한다.
- 비교 목록·검색 조건·생활 가이드 대화는 메모리에만 유지된다. 새로고침하거나 다른 도메인으로 이동하면 초기화된다.
- 이 문서는 저장공간의 이전 특성을 설명한다. Vercel 배포 설정은 [README](../README.md), 자료 범위는 [자료·검색 기준](DATA_AND_MATCHING.md)을 확인한다.
